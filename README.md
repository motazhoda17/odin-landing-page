# odin-landing-page

My landing page for The Odin Project, built from a design they provided.

## What I did
Recreated the design using only HTML and CSS.

## How
- Used Flexbox to place elements side by side
- Wrapped content in container divs to control the layout
- Centered sections using max-width and margin: 0 auto

## What I learned
How to break a design into boxes and decide which ones need to be flex containers.
